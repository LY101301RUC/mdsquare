# Security Policy

## Supported Versions

MdSquare is currently an MVP source project. There is no signed, notarized, or supported binary release yet.

Security fixes are applied to the latest commit on the default branch. Older commits and local development branches are not supported release lines.

## Reporting A Vulnerability

If GitHub private vulnerability reporting is enabled for this repository, use it to submit the issue privately.

If private reporting is unavailable, open a minimal public issue asking the maintainer to establish a private contact channel. Do not include exploit code, sensitive file contents, access tokens, or enough detail to reproduce an unresolved vulnerability in that public issue.

Useful private reports include:

- affected commit or version;
- expected and observed behavior;
- minimal reproduction steps;
- impact and realistic attack conditions;
- any suggested mitigation.

The maintainer will acknowledge a complete private report, assess scope, and coordinate disclosure after a fix is available. No fixed response-time guarantee is made while the project remains an MVP.
