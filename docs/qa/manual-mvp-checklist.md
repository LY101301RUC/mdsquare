# MdSquare MVP 手工验收清单

## 欢迎页

- [ ] 直接打开 `MdSquare.app` 会显示欢迎页，而不是自动弹出 Finder 风格的文件选择面板。
- [ ] 欢迎页顶部显示应用图标，而不是文字 fallback。
- [ ] 欢迎页背景显示淡水墨山水，铺满窗口底部，并且不会影响标题、按钮和最近文件列表的可读性。
- [ ] 点击“打开文件”会弹出系统文件选择面板，并可选择 `.md` 或 `.markdown` 文件。
- [ ] 选择文件后欢迎页会关闭，保留打开的 Markdown 编辑窗口。
- [ ] 打开过的文件会出现在“过往文件”列表中。
- [ ] 点击“过往文件”中的条目会打开对应文件并关闭欢迎页。

## 文档读写

- [ ] `./script/build_and_run.sh --verify` 可以启动 `MdSquare`。
- [ ] 在 Finder 中为 `.md` 文件选择“打开方式”时，选中 `dist/` 中的应用后可以看到 `MdSquare.app`。
- [ ] 打开 UTF-8 编码的 `.md` 文件后，编辑区能显示文件文本。
- [ ] 编辑一行文本后按 `Cmd+S`，可以保存最新的编辑内容。
- [ ] 用工具栏加粗、引用或代码块修改文本后立刻按 `Cmd+S`，关闭并重新打开后内容仍是最新文本。
- [ ] 关闭并重新打开该文件后，可以看到刚才保存的文本。
- [ ] 如果原文件被删除，文档窗口顶部会提示“原文件已不存在”。
- [ ] 如果原文件被其他应用修改，文档窗口顶部会提示继续保存可能覆盖外部更改。
- [ ] `File > New` 可以创建一个空文档，并能保存为 `.md` 文件。
- [ ] 打开非 UTF-8 文件时会显示打开错误，并且不会重写原文件。

## 布局

- [ ] 左侧大纲栏较窄。
- [ ] 左侧大纲栏和编辑区之间没有可拖拽分割条或白色空带。
- [ ] 编辑区和预览区宽度一致。
- [ ] 鼠标移动到编辑区和预览区的分割线附近时，会显示左右拖拽指针。
- [ ] 拖拽编辑区和预览区分割线时，比例变化平滑。
- [ ] 在三栏、写作、阅读和专注模式之间切换时，可见区域符合模式预期，预览区不会空白消失。
- [ ] 调整窗口大小后，三个区域仍然可用。
- [ ] 窗口缩放过程中，编辑区和预览区保持相同的弹性宽度关系。
- [ ] 没有标题的文件会在大纲栏显示“暂无大纲”空状态。

## 窗口与标签页

- [ ] 在 `View > Show Tab Bar` 打开标签栏后，从 Finder 或 Open With 再打开另一个 `.md` 文件，会加入当前 MdSquare 窗口的标签页，而不是弹出独立窗口。
- [ ] 调整文档窗口大小后，标题栏保持统一浅色背景，并与正文区域保留清晰分隔线。

## Markdown 预览

- [ ] 标题可以在预览区正常渲染。
- [ ] 任务列表会渲染为不可编辑的复选框。
- [ ] 表格会渲染为表格。
- [ ] 原始 `<script>` 文本会被转义或保持惰性，不会执行。
- [ ] 远程 Markdown 图片会渲染为惰性的 blocked-image 文本，不会发起网络请求；符合限制的同目录本地图片可以显示。
- [ ] `javascript:` 链接不会发生跳转。
- [ ] `https:` 链接会在预览 WebView 外部打开。

## 导航

- [ ] 点击大纲项后，编辑区会滚动到对应标题。
- [ ] 点击大纲项后，预览区会滚动到对应标题。
- [ ] ATX H1-H6 标题会出现在大纲中。
- [ ] Setext H1/H2 标题会出现在大纲中。
- [ ] fenced code block 内部的标题不会出现在大纲中。

## 编辑命令

- [ ] 标题工具栏命令会重写当前行的标题标记。
- [ ] 加粗命令会用 `**` 包裹选中文本。
- [ ] `Command+B` 会对选中文本执行加粗，行为和工具栏加粗一致。
- [ ] 对已经加粗的选中文本再次点击加粗，会移除 `**` 标记。
- [ ] 斜体命令会用 `*` 包裹选中文本。
- [ ] `Command+I` 会对选中文本执行斜体，行为和工具栏斜体一致。
- [ ] 对已经斜体的选中文本再次点击斜体，会移除 `*` 标记。
- [ ] 链接命令会插入 `[text](url)`。
- [ ] `Command+K` 会插入链接，行为和工具栏链接一致。
- [ ] 文字颜色菜单可以把选中文本标记为红色或蓝色，并在编辑区中以对应颜色高亮正文内容。
- [ ] 红色和蓝色文字颜色可以在预览区安全渲染；其他颜色 HTML 不会被放行。
- [ ] 列表、引用和代码块命令会转换选中的行。
- [ ] 对已经引用的当前行或选中行再次点击引用，会移除 `>` 标记。
- [ ] 撤销操作会把每一次工具栏动作作为一次编辑来回退。

## 外观

- [ ] 浅色模式下，正文和标题颜色清晰可读。
- [ ] 深色模式下，正文和标题颜色清晰可读。

## 性能观测

- [ ] 运行 `node script/measure_core_perf.mjs` 可以输出 100KB 和 1MB 文档的预览渲染耗时。
- [ ] 运行 `node script/measure_core_perf.mjs --budget`，100KB 和 1MB 预览渲染不超过本地预算。
- [ ] 运行 `./script/test.sh` 可以输出 100KB 和 1MB 文档的标题提取耗时，并且不设置硬性耗时阈值。

## 本地打磨验收

- [ ] 快速连续点击同一个工具栏按钮两次，两个动作都会生效或按预期切换。
- [ ] 工具栏动作可以被一次 `Cmd+Z` 撤销。
- [ ] `Cmd+F` 会打开编辑区的原生查找界面，`Cmd+G` / `Shift+Cmd+G` 可以跳转匹配项。
- [ ] 光标移动到不同章节正文时，左侧大纲高亮会跟随变化，编辑区和预览区不会因此跳动。
- [ ] 在编辑区点击不同标题下的正文并短暂停留，预览区会滚动到对应标题附近。
- [ ] 快速连续输入时，预览区不会疯狂跳动。
- [ ] 底部状态栏会随输入更新行数、词数、字符数、标题数和当前位置。
- [ ] 对 1MB 测试文档输入文字时，编辑区不会出现明显卡死。
- [ ] 欢迎页会自动移除已经不存在的过往文件。
- [ ] 未保存改动产生的本地草稿会出现在欢迎页“可恢复草稿”区域。
- [ ] 点击“可恢复草稿”条目会打开一个 recovered `.md` 副本，不会直接覆盖原文件。
- [ ] 文档窗口调整大小后，重新打开应用时尺寸体验保持稳定。
- [ ] 工具栏 tooltip/help 文案为中文。
